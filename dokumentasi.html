HYPECAL - DOKUMENTASI LENGKAP

Aplikasi Kalender Konten Sosial Media Offline (Neo-Brutalism UI)

1. Pengantar & Fitur Utama

HypeCal adalah aplikasi berbasis Web App / Progressive Web App (PWA) 100% Offline yang dirancang khusus untuk Social Media Specialist. Menggunakan teknologi Vanilla JS, TailwindCSS, dan IndexedDB.

  • Neo-Brutalism Design: UI berani, garis tebal, hard shadow.
  • 100% Offline (IndexedDB): Data tersimpan di browser user. Tidak butuh server/database MySQL.
  • State Persistence (Anti-Data Loss): Mengetik judul lalu merefresh web? Data form tidak akan hilang.
  • Export/Import Excel: Backup data secara manual dengan mudah.
  • Dark Mode & Custom Theme: Ubah warna sesuka hati via Pengaturan.

2. Panduan Folder CodeCanyon (Pemisahan File)

Aplikasi ini diberikan dalam bentuk Single File HTML (index.html) agar mudah dicoba. Namun, untuk struktur produksi CodeCanyon, Anda harus memecahnya. Ikuti komentar di dalam file index.html!

  1. Buka index.html. Cari tag <!-- FILE: source/assets/css/style.css START -->.
  2. Cut (Potong) semua kode CSS yang ada di dalamnya dan Paste ke dalam file baru bernama style.css (letakkan di folder assets/css/).
  3. Cari tag // FILE: source/assets/js/app.js START.
  4. Cut semua kode JavaScript di dalamnya dan Paste ke dalam file app.js (letakkan di folder assets/js/).
  5. Panggil kembali file-file tersebut di dalam index.html menggunakan tag <link> dan <script src="...">.

3. Panduan Modifikasi PWA & Icon

Agar aplikasi bisa di-install di HP dengan logo Anda, ikuti langkah ini:

  • Siapkan logo aplikasi Anda dengan format .png. Pastikan backgroundnya solid (tidak transparan) untuk desain Brutalism.
  • Buat dua ukuran pasti: 192x192 pixels dan 512x512 pixels.
  • Ubah nama file tersebut menjadi icon-192x192.png dan icon-512x512.png.
  • Masukkan kedua file tersebut ke dalam folder assets/.
  • Aplikasi akan otomatis membacanya melalui file manifest.json.

4. Panduan Hosting / Instalasi

Aplikasi ini adalah file statis (HTML/CSS/JS). Cara uploadnya sangat mudah:

  1. Menggunakan cPanel: Login cPanel > Buka File Manager > Masuk ke folder public_html > Upload seluruh file (index, manifest, sw.js) ke dalamnya.
  2. Menggunakan GitHub Pages (Gratis): Buat repository baru > Upload file-file ini > Buka tab Settings > Pages > Pilih branch "main" > Save. Web Anda langsung online!
  3. Penting: Service Worker (PWA) HANYA berjalan jika domain Anda menggunakan HTTPS (SSL). Pastikan SSL website Anda aktif.

5. Panduan Penggunaan Harian

  • Master Kategori: Buka menu ini pertama kali. Tambahkan kategori platform (misal: TikTok, IG Reels) beserta warna labelnya.
  • Kalender Post: Klik "Buat Post". Input judul, jadwal, dan kategori. Data yang belum disimpan otomatis menjadi "Draf".
  • Geser Tutup (Mobile): Saat form muncul di layar HP, sentuh dan tarik garis tebal di bagian atas panel ke arah bawah untuk menutup form dengan cepat.
  • Cetak Laporan: Di menu Kalender, klik "Cetak PDF". UI Brutalism (warna latar/shadow) akan dihilangkan otomatis agar bersih saat dicetak di kertas HVS.
